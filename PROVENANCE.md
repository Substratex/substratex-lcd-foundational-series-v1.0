# Scientific Lineage & Provenance Declaration

This repository preserves the foundational manuscript series of the scientific and engineering program originated and developed by **Arjay Asadi**, Founding Architect of **SubstrateX®** and creator of **SubstrateX Aperture™**.

The program investigates **Intelligence in Motion™**: the observable development of computational behavior across extended runtime.

Its current scientific framework is **Longitudinal Computational Dynamics® (LCD)**. Its primary empirical object is **Longitudinal Computational Behavior**: the source-bound organization of computational activity as it forms, moves, recurs, drifts, stabilizes, enters regimes, crosses declared boundaries, collapses, recovers, or re-enters supported operating conditions through time.

## Historical lineage

The current program emerged from a continuous body of research developed from **2024 through 2026**, including earlier investigations published under the **Recursive Science®** research program. Those earlier works examined inference-phase dynamics, runtime intelligence, recursive behavioral formation, coherence, continuity, drift, collapse, recovery, temporal structure, and related runtime phenomena.

Those publications remain part of the documented historical lineage of the current work. The present series consolidates, narrows, operationalizes, and re-expresses that lineage within the current hierarchy:

**Intelligence in Motion™** → **Longitudinal Computational Dynamics®** → **Longitudinal Computational Behavior** → **Runtime Evidence** → **Computational Behavior Architecture / Chronodynamics** → **Evidence-Governed Computation™** → **SubstrateX Aperture™**.

This transition is not merely a renaming exercise. The decisive advance is the movement from conceptual runtime theory toward an integrated scientific and computational architecture in which extended computational behavior can be reconstructed, measured, instrumented, investigated, governed by evidence, reproduced under declared conditions, and preserved.

## Reference implementation

**SubstrateX Aperture™** is the principal operational reference implementation associated with the series. Aperture demonstrates how heterogeneous operational records can be qualified, canonicalized, reconstructed into longitudinal computational trajectories, measured through governed instrumentation, bound to a common evidence identity, investigated through reversible source relationships, constrained by explicit claim boundaries, and preserved as Runtime Evidence.

Implementation demonstrates executability and architectural integration. It does not by itself establish universal scientific validity. Construct validity, calibration, prospective performance, cross-domain transport, and independent replication remain separate empirical questions.

## Provenance principle

The repository preserves authorship and chronology through:

- immutable manuscript versions;
- Git history and signed or annotated release tags where available;
- release manifests;
- SHA-256 hashes;
- explicit series numbering;
- versioned citation metadata;
- preservation of superseded editions rather than silent replacement.
