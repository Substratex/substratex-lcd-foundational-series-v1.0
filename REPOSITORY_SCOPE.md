# Repository Scope

This repository is a **publication and provenance archive**, not the SubstrateX Aperture™ application repository and not the EGC Web Framework repository.

It contains or is intended to contain:

- the seven foundational manuscripts in the LCD series;
- release and citation metadata;
- copyright and research-access notices;
- provenance records and checksums;
- publication policies and archival guidance;
- historical-lineage notes where necessary to preserve continuity.

It does **not** by itself grant access to:

- the complete Aperture implementation;
- proprietary calibration data;
- unreleased algorithms or thresholds;
- private validation corpora;
- production deployment infrastructure;
- commercial licenses;
- certification authority.

Software and executable artifacts may be referenced from this archive but remain governed by their own repositories and licenses.
