**SubstrateX® Longitudinal Labs**

This repository is the canonical public archive for the seven-paper foundational manuscript series developed by **Arjay Asadi**, Founding Architect of **SubstrateX®** and creator of **SubstrateX Aperture™**.

The series establishes the scientific, evidentiary, representational, temporal, and implementation foundations of the SubstrateX research program around **Longitudinal Computational Dynamics® (LCD)** and **Longitudinal Computational Behavior**.

## Repository purpose

This archive is designed to preserve:

- manuscript identity and version history;
- authorship and scientific provenance;
- stable citation metadata;
- release hashes and immutable publication records;
- the relationship between the scientific series and SubstrateX Aperture™;
- the historical lineage from earlier Recursive Science® research into the current LCD / Runtime Evidence / EGC architecture.

The manuscripts themselves should be added manually to their corresponding folders in `papers/`. Prefer publishing both the authoring format and a fixed-render PDF when available.

## Recommended release practice

Do **not** overwrite a previously published manuscript file. Add a new version and preserve the old release. Every release should receive:

- a semantic version;
- a Git tag;
- SHA-256 hashes;
- a dated release manifest;
- stable citation metadata;
- a short release note describing substantive changes.

See `PUBLISHING_POLICY.md` and `provenance/README.md`.
