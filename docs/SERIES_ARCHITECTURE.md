# Series Architecture

The seven manuscripts are intentionally layered rather than independent.

**Paper 1 — Foundations of LCD** establishes the scientific field and empirical object.

**Paper 2 — Validation** reports bounded computational reproducibility and controlled discrimination propositions.

**Paper 3 — Runtime Evidence** defines the source-bound evidentiary object connecting science and implementation.

**Paper 4 — Computational Behavior Architecture** defines the implementation-independent representational structure through which observable runtime activity becomes reconstructable and investigable.

**Paper 5 — Evidence-Governed Computation** defines the general architectural discipline governing evidence authority, claim admissibility, bounded projection, surface binding, and preservation.

**Paper 6 — Chronodynamics** defines the specialized temporal science of LCD, including symbolic time, temporal authority, marker semantics, and prospective validity.

**Paper 7 — Aperture Methods** documents the integrated reference implementation and methodological realization in SubstrateX Aperture™.

The ordering is designed to move from scientific object → validation → evidence object → representation → governance → temporal theory → integrated methods.
