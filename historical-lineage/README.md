# Historical Lineage

Earlier research published under the **Recursive Science®** program remains part of the documented provenance of the current SubstrateX® research program.

This repository does not silently rewrite those historical works. Instead, the present series records the current canonical hierarchy and preserves the earlier program as foundational lineage.

Historical editions may be archived here later if Arjay Asadi elects to preserve them publicly. They should remain clearly labeled as historical and should not be confused with the current Longitudinal Computational Dynamics® series.
